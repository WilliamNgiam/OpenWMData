    Wang and van Ede (2025)

    Re-focusing visual working memory during expected and unexpected memory tests

    [Paper] [Data] [Analysis Code]

    How we deploy attention to external sensory inputs is classically studied by contrasting anticipatory orienting following predictive cues with subsequent re-orienting to unexpected perceptual targets. How we deploy internal attention to representations held in visual working memory has primarily been studied during anticipatory orienting following retrocues, leaving open how internal attention is deployed and re-focused once a memory test actually occurs. Here, we manipulated retrocue reliability in a visual working memory orientation reproduction task to compare internal attentional deployment following memory tests that were certain, expected, or unexpected. Using EEG-alpha lateralization and spatial biases in gaze/microsaccades to track internal attention in space, we uncovered a second stage of internal attentional deployment after the presentation of the central memory test. Following expected memory tests, internal attention was deployed again to the tested item independently of prior orienting, consistent with an internal verification or “double-checking” process. Following unexpected memory tests, re-focusing attention toward the alternative memory content was significantly prolonged, reflecting a revision of the internal focus of attention.
